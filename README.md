# e-plantShopping

Welcome to **e-plantShopping**, an e-commerce web application for Paradise Nursery built using React and Redux Toolkit.

## Project Overview
This application features:
- **Landing Page:** Introduces Paradise Nursery with a background banner and a "Get Started" button.
- **Product Listing Page:** Displays houseplants organized into categories (Air Purifying, Aromatic, Low Maintenance) with "Add to Cart" options.
- **Shopping Cart Page:** Allows users to adjust item quantities, view live subtotals/totals, remove items, and proceed to checkout.

## Technologies Used
- React
- Redux Toolkit
- JavaScript (ES6+)
- CSS3
